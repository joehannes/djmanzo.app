# Pictures still to make

The site's paintings (`public/v4/art/`, `public/shop/art/`) were generated
with FLUX.2 [klein] 4B on Cloudflare Workers AI (weights Apache-2.0; see
`docs/WEBSITE.md` and djmanzo's `docs/RESEARCH.md`), converted to WebP. The
session that built the road ahead, the scenes and the sounds (24 October)
had no Cloudflare token and no image model, so these were written down
instead of made. Each is one prompt, the file it becomes, and where it is
shown. Keep the house rules: no logos, no brand names on gear, no readable
text, no real person's likeness, people seen from behind or in silhouette.

Common style line, appended to every prompt:
`cinematic editorial photograph, shallow depth of field, warm practical lights, rich shadows, 35mm, high detail, no text, no logos`
