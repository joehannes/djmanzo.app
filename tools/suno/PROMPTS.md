# Suno prompts for the deck's loops and the booth's sounds

Custom mode. **Style** goes in Styles, the bracketed block in Lyrics, the **Exclude** line in Exclude styles where your version has it. Each generation gives two versions: download the better one as WAV where the plan allows, named as shown, and cut it with `cut-loops.sh` or `cut-fx.sh` here: they need no listening to find the cuts, because each song is built to a fixed grid.
